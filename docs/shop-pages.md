# 자사몰 고객 화면 목록 (2026-10-29)

29CM 고객 화면 흐름을 참고했다: 상품 → 장바구니 → 주문서 → 결제 → 주문 완료 → 마이페이지. 흑백 · 얇은 선 · 큰 제목 · 둥근 상자 없음.
경로 → 화면은 `src/Root.jsx`. 서버 API 는 SHOP-BE (`/api/shop` → `https://api.eidofood.com/shop`).

```
Today (메인) /                      App.jsx — 메뉴 첫째, 기획 큐레이션 (지금은 디자인 시안)
├─ Shop (메뉴 둘째)
│  ├─ 목록 /products?q=&page=        검색 · 메뉴 단어 · 4열 그리드 · 40개씩 페이지
│  └─ 상세 /products/:code           사진(썸네일) · 옵션 · 수량 · 장바구니 · 바로구매
│                                     └ 탭: 상품 상세(AGC 상세 이미지) · 상품 정보 · 배송·교환·환불
├─ 장바구니 /cart                     선택 · 수량 · 삭제 · 결제 예정 금액 → 주문하기 (비로그인이면 로그인)
├─ 주문
│  ├─ 주문서 /order/checkout          주문 상품 · 배송지(저장 배송지/새로 입력, 주소 찾기) · 배송 메모
│  │                                  · 개인통관고유부호 · 결제 수단(카카오/네이버) · 동의 → 결제
│  ├─ 결제사에서 돌아오는 곳 /pay/…    승인 → 주문 완료로 (src/pay/PayPages.jsx)
│  └─ 주문 완료 /order/complete       주문번호 · 금액 · 받는 분 → 주문 상세 / 쇼핑 계속
├─ 회원
│  ├─ 로그인 /login?next=
│  └─ 회원가입 /signup                 이메일 · 비밀번호 · 이름 · 휴대폰(선택) · 필수 약관 3 + 광고(선택)
├─ 마이페이지 /my                      왼쪽 메뉴 + 진행 상태 숫자 4칸 + 최근 주문 5개
│  ├─ 나의 쇼핑
│  │  ├─ 주문 · 배송 조회 /my/orders  탭: 전체 · 진행 중 · 취소
│  │  └─ 주문 상세 /my/orders/:code   진행 단계 · 송장 · 상품 · 배송지 · 결제 · 주문 취소(상품 준비 전만, 전액 환불)
│  └─ 나의 정보
│     ├─ 회원정보 수정 /my/profile     이름 · 휴대폰 · 통관부호 · 광고 수신 · 회원 탈퇴
│     ├─ 배송지 관리 /my/addresses     추가 · 수정 · 기본 · 삭제 (10개까지)
│     └─ 비밀번호 변경 /my/password    바꾸면 다른 기기 로그아웃
├─ Story /story (메뉴 셋째) ········· MKT 팀 글이 올라갈 자리 — 지금은 준비 중 화면
├─ 안내 (초안 — 오픈 전 검토)
│  ├─ 이용약관 /terms

│  └─ 해외구매대행 안내 /guide
```

## 서버가 지키는 것
- 금액은 서버가 계산 (자사몰가 = AGC 네이버 판매가 × 0.95, 100원 올림 — **임시 규칙**, `SHOP_PRICE_RATE`).
- 실제 상품 주문은 로그인 · 배송지 · 통관부호(P+12자리) · 동의가 있어야 만들어진다.
- 연락처 · 주소 · 통관부호는 암호화 저장. 화면에는 통관부호를 가려서(`P12*******012`) 보여준다.
- 고객 취소는 결제 완료 + 주문 접수 단계에서만 → 결제사 전액 취소.
- 상세 이미지는 확인 표시 `[[...]]` 가 없는 승인 페이지만 (지금 200개 중 15개).
